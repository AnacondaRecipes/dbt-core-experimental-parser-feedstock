Installing dbt-core-experimental-parser
==================

Installing `dbt-core-experimental-parser` from the main channel can be achieved by:

```
conda install dbt-core-experimental-parser
```

It is possible to list all of the versions of `dbt-core-experimental-parser` available on your platform with `conda`:

```
conda search dbt-core-experimental-parser
```
